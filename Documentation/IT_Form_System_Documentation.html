1. System Overview

The IT Management Portal is a comprehensive internal web application designed to digitize and streamline the entire employee IT lifecycle — from onboarding through transfers to offboarding — while simultaneously managing IT assets, software licenses, and organizational configuration. The system replaces paper-based forms with a multi-step digital workflow featuring digital signatures, SLA tracking, email notifications, audit logging, and PDF document generation.

Key Capabilities

  • Employee Onboarding — Multi-step wizard for HR to request IT setup for new hires (accounts, assets, software, permissions).
  • Employee Offboarding — Structured clearance and deprovisioning workflow with hardware return tracking.
  • Employee Transfer — Department/branch transfer management with return + re-provisioning checklists.
  • IT Asset Management — Full hardware inventory with lifecycle tracking, maintenance logs, warranty monitoring, and device verification.
  • Software License Management — Catalog of standard software, license editions, encrypted key vault, and assignment tracking.
  • Digital Signatures — HMAC-verified signature capture for HR, HOD, IT Admin, and Employee sign-off.
  • SLA Tracking — Configurable target days with two-tier escalation email notifications.
  • Audit Trail — Automatic change-tracking on all entities with email alerts for critical events.
  • Dashboard Analytics — Role-based dashboards with KPIs, trend charts, YoY comparison, and SLA compliance.
  • Directory Services — Email contact directory, email groups, shared mailboxes, and server folder management.

4. User Roles & Authorization

The system uses a claims-based authorization model via the UserTitle entity. Each user can hold one or more titles, which are transformed into claims at login by UserTitleClaimsTransformation.

Role (Title)ClaimAccess Scope
IT IT AdminUserTitle:ITFull system access: asset management, license management, onboarding IT steps, offboarding IT checklist, configuration, user management, audit logs, dashboard analytics
HR HR StaffUserTitle:HRCreate onboarding/offboarding/transfer requests, HR signing, HR dashboard with workforce analytics
MGR Manager / HODUserTitle:ManagerHOD approval signing for offboarding, transfer approval, manager dashboard
EMP Employee(Authenticated)Employee self-service signing via secure token link, email signature viewer

Authorization Policies

RequireHRUser must have UserTitle:HR claimOnboarding Create, Offboarding Create

Multi-Company Access

Users are associated with one or more companies via the UserCompany join table. All data queries are automatically scoped to the user's assigned companies, ensuring data isolation between branches.

5. Module Descriptions

5.1 Employee Onboarding

Controller: OnboardingController | Model: OnboardingRequest

A multi-step wizard that guides HR through the complete new-hire IT provisioning process:

StepOwnerDescription
Step 1HREmployee details (name, ID, department, branch, join date, contact info, HOD email)
Step 2HRSoftware requirements checklist (dynamic from StandardSoftware catalog), email groups, shared mailboxes
Step 3ITAsset assignment (link ITAsset records), software license allocation, server folder permissions
Step 4ITIT setup checklist (O365, domain join, WiFi, printer, VPN, etc.), requester digital signature
Step 5EmployeeEmployee acknowledgement signature + PDPA consent (via secure token link)

5.2 Employee Offboarding

Controller: OffboardingController | Model: OffboardingRequest

Structured clearance workflow for departing employees with optional link to their onboarding record:

  • HR initiates with employee details and last day of work
  • Clearance checklist (laptop, mobile, keys, other assets returned)
  • IT deprovisioning checklist (AD disable, email forwarding, license revocation, etc.)
  • Hardware return tracking with damage assessment, photo upload, and missing item fines
  • Four-party signature flow: HR → HOD → IT Admin → Employee
  • Follow-up actions: data backup, email backup, license removal

5.3 Employee Transfer

Controller: EmployeeTransferController | Model: EmployeeTransfer

Handles department/branch transfers with a dual-checklist approach:

  • Return Checklist — Mirrors offboarding: deactivation of old department resources
  • Setup Checklist — Mirrors onboarding: provisioning of new department resources
  • Hardware return tracking with clearance items
  • Re-assignment of email groups, shared mailboxes, software, and folder permissions

5.4 IT Asset Management

Controller: ITAssetController | Model: ITAsset

  • Full CRUD for hardware assets (laptops, desktops, monitors, peripherals)
  • Asset types: Laptop, DesktopPC, Monitor, USB, Keyboard, Headset, DockingStation, Webcam, Others
  • Status tracking: Available, Issued, UnderRepair, Disposed, Lost
  • Hardware specs: RAM, Storage, CPU, DDR Type, Windows Version, Hardware Hash
  • Warranty expiry monitoring with automated email notifications
  • Maintenance log history with cost tracking
  • Device verification via PowerShell/batch agent scripts
  • Soft-delete with unique asset tag constraint on active records

5.5 Software License Management

Controller: StandardSoftwareController | Models: StandardSoftware, SoftwareLicense, SoftwareKey

  • StandardSoftware — Master catalog of software types (e.g., "Microsoft Office")
  • SoftwareLicense — Edition/version records under each catalog entry with contract limits
  • SoftwareKey — Individual license keys, encrypted at rest (AES-256), with assignment tracking
  • Utilization analytics (total vs. assigned), expiry tracking, vendor management

5.6 Dashboard & Analytics

Controller: HomeController | Model: DashboardViewModel

Role-specific dashboards with:

  • IT Dashboard: Unified pending task queue, asset distribution, license utilization, hardware analytics (CPU/RAM/Storage), maintenance stats, expiring warranties
  • HR Dashboard: Workforce trends, department/branch breakdowns, net growth, avg processing time, rejection rates, SLA bottleneck analysis, YoY comparisons

10. Security Architecture

Authentication

  • Password Policy: Min 10 chars, uppercase + lowercase + digit + special char, 4 unique chars (NIST SP 800-63B)
  • Password Hashing: Argon2id (replaces default PBKDF2)
  • Account Lockout: 5 failed attempts → lockout with progressive duration
  • Forced Password Change: Middleware redirects users with MustChangePassword flag
  • OTP: Email-based one-time passwords for password reset
  • Session: 30-minute idle timeout, 4-hour absolute expiry, HTTP-only cookies

Data Protection

  • Column Encryption: AES-256 on PII fields (Employee IDs, Emails, License Keys)
  • Signature Integrity: HMAC-SHA256 verification on all digital signatures
  • Soft Deletes: Records are never physically deleted — marked with IsDeleted, DeletedAt, DeletedByUserId
  • PDPA Compliance: Automated data retention service purges PII after retention period

Application Security

  • CSRF: Global auto-validate antiforgery tokens on all non-GET requests + custom header support
  • Rate Limiting: Fixed window — 100 req/min (general), 10 req/min (strict endpoints)
  • Security Headers: CSP, X-Frame-Options, X-Content-Type-Options via middleware
  • Cookie Security: SameSite=Strict, HttpOnly, Secure in production
  • Kestrel: Server header removed for fingerprint masking
